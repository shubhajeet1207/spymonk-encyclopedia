# SpyMonk Encyclopedia

A research workspace that answers only from verified, cited evidence. It searches its saved archive first, and researches the public web only when asked.

This Space is deployed from the SpyMonk repository with `scripts/deploy_hf_space.py`; edit the repository, not this Space. Your archive lives in a private backup dataset, so it survives restarts.
