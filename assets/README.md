## README banner

[`spymonk-technical-banner.svg`](spymonk-technical-banner.svg) is the editable, **1600 × 600** vector banner used by the root README.

The design combines a graphite/plum canvas, coral typography, a fine technical grid, and an abstract evidence circuit. The circuit illustrates web sources → cross-checks → saved memory → cited answers; it is not a screenshot or a guarantee that a claim is true. The coral and warm-paper tones echo the application's visual palette.

All graphics are SVG paths, shapes, and text. There are no photos, embedded raster images, remote font/image dependencies, scripts, or animation. The file includes an accessible title and description and scales to the README's available width.
